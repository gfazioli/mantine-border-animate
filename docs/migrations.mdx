## Upgrade guide

This page collects the **breaking changes** and **migration steps** for each major version of `@gfazioli/mantine-border-animate`. If you are starting a new project, you can skip this page — everything here is about updating existing code from an older version.

New features introduced in a release (that do not break anything) are **not** listed here. See the [GitHub Releases](https://github.com/gfazioli/mantine-border-animate/releases) page or the newsletter for the full changelog.

## v3

Version 3.0 renames a handful of props so that each one means exactly one thing, and adds two
variants plus a third beam mode. It also **fixes how some variants render**, which is why the
release is a major even though most codebases only need a find-and-replace: if you relied on the
broken behaviour, the border will look different after the upgrade.

### Rendering fixes that change how v2 looked

These need no code change, but they do change pixels:

- **The glow is visible inside a Card, a Paper or any container with a background.** Its
  <Code>z-index: -1</Code> used to escape the component, so it painted behind the background of
  the first ancestor that had one. The root now creates a stacking context.
- **borderWidth thickens the pulse border instead of breaking it.** Above 1px the gradient only
  covered a hairline of the masked band and the corners were left empty; a wide pulse border was
  four disconnected lines. It is now a full, correctly rounded ring.
- **The dot beam rides the middle of the border band** rather than its outer edge, so a small
  <Code>size</Code> with a wide <Code>borderWidth</Code> is no longer half clipped away.

### Migration examples

**Rename the position prop, and rescale it:**

```tsx
// Before
<BorderAnimate animate={false} angle={90} />

// After — 90° of 360 is 25% of the perimeter
<BorderAnimate animate={false} progress={25} />
```

**Rename the beam modes:**

```tsx
// Before
<BorderAnimate beamMode="path" size="lg" />
<BorderAnimate beamMode="conic" size="md" />

// After
<BorderAnimate beamMode="dot" size="lg" />
<BorderAnimate beamMode="wedge" spread={72} />
```

**Rename the stagger prop:**

```tsx
// Before
<BorderAnimate delay={1.5} />

// After
<BorderAnimate phase={1.5} />
```

In development, passing any of the old props logs a one-time warning pointing back to this page.

#### Migration examples

**Rename `opacity` to `borderOpacity`:**

```tsx
// Before
<BorderAnimate opacity={0.5} />

// After
<BorderAnimate borderOpacity={0.5} />
```

**Replace `variant="gradient"` with conic beam + colorStops:**

```tsx
// Before
<BorderAnimate variant="gradient" colorFrom="red" colorTo="blue" />

// After
<BorderAnimate
  beamMode="conic"
  colorStops={[
    { color: 'red', position: 0 },
    { color: 'blue', position: 50 },
    { color: 'red', position: 100 },
  ]}
/>
```

**Remove `anchor` and `count` props:**

```tsx
// Before
<BorderAnimate anchor={50} count={3} />

// After
<BorderAnimate />
```
